SSRF + denegación de servicio vía validación de esquemas (CVE-2026-116686)

Cuando un CLIENTE de MCP valida el resultado estructurado de una herramienta contra el outputSchema que el propio SERVIDOR le mandó, y usa jsonschema con su resolución de referencias por defecto, un servidor malicioso puede meter un $ref que apunte a una URL externa — el cliente termina haciendo esa petición él mismo (SSRF). Peor todavía: si esa llamada de red es SÍNCRONA (urllib.request.urlopen) dentro de una función async def, un único endpoint "tarpit" que nunca responde congela el event loop entero del proceso. Motivado por CVE-2026-116686 (CVSS 6.5) en el SDK oficial de Python de MCP. Pegá acá el código del lado cliente que valida esquemas, o que hace llamadas de red dentro de una función async.
